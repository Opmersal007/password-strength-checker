
# 🔐 Password Strength Checker

A Python-based cybersecurity learning project that
evaluates passwords using five basic validation rules
and provides automatic improvement suggestions.

## ✨ Features

- Modern dark-themed graphical interface
- Password strength scoring (0–5)
- Weak, Medium and Strong classification
- Colourful password strength indicator
- Show and Hide Password functionality
- Automatic password improvement suggestions
- Clear Password button
- Terminal and desktop versions

## 🛠️ Technologies Used

- Python
- Tkinter
- Visual Studio Code
- GitHub

## 📂 Project Structure

- main.py - Terminal-based application
- gui.py - Graphical desktop application
- README.md - Project documentation

## 🚀 How to Run

1. Download or clone this repository.
2. Install Python 3 with Tkinter support.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the application using:

   python gui.py

For the terminal version:

   python main.py

## 📊 Password Validation Rules

- Minimum 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one supported special character

## 🔒 Security Disclaimer

This project is designed for educational purposes.
Its basic scoring system does not guarantee password
security. Use sample passwords when testing.
